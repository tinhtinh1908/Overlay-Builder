DTinh Overlay Builder 2.8

- Xóa hoàn toàn chức năng đóng gói module KernelSU.
- Thêm tùy chọn tạo đồng thời values, values-vi và values-zh-rCN.
- Chuyển thư mục build tạm sang thư mục TEMP của hệ thống.
- BUILD_EXE không còn để lại build, dist hoặc file spec trong thư mục tool.
- Rút gọn tools xuống đúng các thành phần AAPT2, zipalign, apksigner và android.jar.
- Dọn build cũ, cache, test cũ và output đóng gói thừa.
